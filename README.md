# 🌸 Sakura Restaurant - ระบบจัดการร้านอาหาร & สั่งอาหารตามโต๊ะ

โปรเจกต์นี้ถูกติดตั้งอยู่ที่: `D:\sakura-restaurant` (หรือ `E:\sakura-restaurant`)

---

## 📁 รายการไฟล์ในโฟลเดอร์นี้

- **`index.html`** : ไฟล์หลักของระบบ (POS, จัดการสต็อก, คำนวณรายได้และค่าคอมมิชชั่น, เปิดบิล, ลิงค์โต๊ะอาหาร 1-12, ซิงค์ข้อมูลเรียลไทม์)
- **`data.json`** : ฐานข้อมูลร้านอาหารฉบับเต็มบนไดรฟ์ D (บันทึกออเดอร์, บิลเปิด, สต็อก, พนักงาน, ค่าคอมฯ แบบ Real-Time อัตโนมัติ)
- **`sakura-restaurant.html`** : ไฟล์สำเนาของระบบ
- **`sakura-stock.html`** : หน้าจัดการสต็อกสินค้า
- **`server.js`** : เว็บเซิร์ฟเวอร์ Node.js สำหรับเปิดใช้งานในร้านผ่าน Wi-Fi (ซิงค์มือถือหลายเครื่องและบันทึกข้อมูลลงฮาร์ดดิสก์)
- **`start-server.bat`** : ดับเบิ้ลคลิกเพื่อเปิดเซิร์ฟเวอร์ทันที

---

## 🚀 วิธีเปิดใช้งานภายในร้าน (Localhost & Wi-Fi)

1. **ดับเบิ้ลคลิกที่ไฟล์:** `start-server.bat`
2. หน้าต่างดำจะแสดงที่อยู่ IP เช่น `http://192.168.1.XX:3000/`
3. มือถือหรือแท็บเล็ตในร้านที่ต่อ Wi-Fi เดียวกัน สามารถเปิดลิงค์ตามโต๊ะได้ทันที:
   - โต๊ะ 1: `http://192.168.1.XX:3000/?table=1`
   - โต๊ะ 2: `http://192.168.1.XX:3000/?table=2`
   - แคชเชียร์/เจ้าของร้าน: `http://localhost:3000/`

## 🌐 วิธีเผยแพร่ออนไลน์ (Publish Online บนอินเทอร์เน็ตฟรี 100%)

คุณสามารถนำโฟลเดอร์นี้ขึ้นอินเทอร์เน็ตเพื่อให้ลูกค้าและพนักงานเปิดได้จากทุกที่ ผ่าน 3 ช่องทางฟรียอดนิยม:

### 1. เผยแพร่ผ่าน Netlify Drop (วิธีที่ง่ายที่สุด - ไม่ต้องเขียนโค้ด)
1. เข้าเว็บไซต์ [app.netlify.com/drop](https://app.netlify.com/drop)
2. ลากโฟลเดอร์ `D:\sakura-restaurant` ไปวางลงในกล่องบนหน้าเว็บ Netlify
3. ระบบจะสร้างลิงค์เว็บไซต์ออนไลน์ให้ทันที เช่น `https://sakura-restaurant.netlify.app`
4. ลูกค้าสามารถเปิดลิงค์ `https://sakura-restaurant.netlify.app/?table=1` สั่งอาหารได้จากทุกที่!

### 2. เผยแพร่ผ่าน Vercel (เร็วและเสถียรมาก)
1. เข้าเว็บไซต์ [vercel.com](https://vercel.com) สมัครบัญชีฟรี
2. ติดตั้ง Vercel CLI หรืออัปโหลดโฟลเดอร์นี้
3. จะได้ชื่อโดเมนฟรี เช่น `https://sakura-restaurant.vercel.app`

### 3. เผยแพร่ผ่าน GitHub Pages
1. นำไฟล์ในโฟลเดอร์นี้อัปโหลดขึ้น GitHub Repository
2. ไปที่เมนู **Settings** > **Pages**
3. เลือก Branch เป็น `main` แล้วกด **Save**
4. เว็บไซต์จะเปิดใช้งานที่ `https://<ชื่อผู้ใช้>.github.io/<ชื่อคลัง>`
